# ציר זמן של החיים (שלב 9)

> מקור: מחקר מתחרים #9 (ציר זמן ותמונות מסופרות). השלמה לספר המורשת: סדר כרונולוגי.

## מה המשתמש חווה
- **המוריש** מוסיף אירועי חיים: כותרת, תאריך (**שנה חובה; חודש ויום אופציונליים** — לא תמיד זוכרים), תיאור קצר, ואפשר לקשר **סיפור** ו/או **תמונה/הקלטה** מהכספת.
- הציר מוצג ממוין כרונולוגית, מקובץ לפי עשור.
- **המוטב** (אחרי הפתיחה) רואה את הציר בעמוד המורשת ובתחילת **ספר המורשת**. קישור לסיפור/קובץ מופיע רק אם מותר לו לראות אותם (אותם כללי קהל ותזמון; קובץ ששמור למסר שלא נמסר — מוסתר). האירוע עצמו (כותרת, תאריך, תיאור) גלוי לכל המוטבים.

## נתונים
`timeline_events`: vault_id, title_enc, description_enc, **date_enc** (`YYYY` / `YYYY-MM` / `YYYY-MM-DD`, מוצפן — תאריכי חיים הם מידע אישי; המיון נעשה אחרי פענוח, עד 300 אירועים), story_id, media_id (FK, `set null`).

## API
| Method | Path | גישה |
|---|---|---|
| GET/POST | `/vault/timeline` · PUT/DELETE `/vault/timeline/:id` | 🔒 מוריש (כספת בבנייה לעריכה) |
| GET | `/inheritances/:vaultId/timeline` | 🔒 מוטב מאושר, כספת פתוחה |
הספר (`/vault/book`, `/inheritances/:id/book`) מקבל שדה `timeline`.

## בדיקות
API: ולידציית תאריך חלקי (לא בעתיד, יום דורש חודש, 30 בפברואר נדחה), מיון, IDOR, קישור לסיפור/קובץ של כספת אחרת נדחה, סינון קישורים למוטב, הופעה בספר. E2E: מוריש מוסיף אירועים ורואה אותם ממוינים + בספר; axe.
