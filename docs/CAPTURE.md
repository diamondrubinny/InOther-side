# לכידה בלי סיסמה, שאלה שבועית ושאלות מהמשפחה (שלב 6)

> מקור: מחקר מתחרים #1, #3, #13. "המחסום הגדול ביותר אצל מבוגרים הוא הכניסה עצמה" (Remento, StoryWorth).
> SMS/WhatsApp — מחוץ להיקף כרגע (דורש ספק, DPA ועלויות). המבנה מוכן: הקישור הוא אותו קישור.

## 1. חוויית המשתמש
- **קישור הקלטה:** המוריש (או ילד/ה בוגר/ת שעוזר/ת לו) יוצר קישור ל**שאלה אחת**. מי שפותח אותו רואה רק את השאלה, כפתור הקלטה גדול ותיבת טקסט. אין סיסמה ואין גישה לשום דבר אחר בכספת. תשובה אחת, תוקף 7 ימים.
  אפשר להעתיק את הקישור (לשלוח בוואטסאפ בעצמכם) או לשלוח אותו **למייל של המוריש עצמו** — לא לכתובת שרירותית (מניעת שימוש לרעה).
- **שאלה שבועית (opt-in):** פעם בשבוע, ביום שבוחרים, מגיע מייל עם שאלה אחת וקישור. קודם שאלה שאושרה מהמשפחה, אחרת השאלה הבאה מהקטלוג שעוד לא נענתה.
- **שאלות מהמשפחה:** מוטב שאישר הזמנה, כל עוד המוריש בחיים, יכול להציע שאלה ("סבא, איך הכרת את סבתא?"). המוריש מאשר (ואז היא נכנסת לתור השבועי או מקבלת קישור מיד) או דוחה. המציע רואה רק סטטוס ("ממתינה", "נענתה — התשובה תחכה לך"). **הוא לעולם לא רואה את התשובה.**
- **התאמה למבוגרים (#13):** בעמוד ההקלטה — טקסט וכפתורים גדולים במיוחד, פעולה אחת בכל מסך, ניסוח ברור, בלי שום דבר לזכור.

## 2. לאן התשובה נכנסת
| מקור השאלה | תשובה בטקסט | הקלטה |
|---|---|---|
| קטלוג | `guided_answers` (מחליפה/מעדכנת) | `media_assets` (תווית = השאלה) → סריקה → תמלול |
| משפחה / מותאמת אישית | `interview_entries` (שאלה + תשובה, מוצפן) → נכנס לחומר של הדמות | כנ"ל |

## 3. אבטחה
- טוקן 256 ביט, נשמר רק כ-SHA-256, נשלח ב-**fragment** (`#token=`) — לא בנתיב ולא ב-query.
- **היקף צר:** הטוקן מאפשר לראות שאלה אחת ולהוסיף תשובה אחת. לעולם לא לקרוא תוכן מהכספת. חד-פעמי, 7 ימים, המוריש יכול לבטל. אחרי פתיחת הכספת / נעילתה — לא עובד.
- Rate limit קשיח לפי IP; טוקן שגוי מקבל תמיד אותה שגיאה (אין enumeration).
- הקלטה עוברת את אותו צינור: הסגר, בדיקת סוג אמיתי, ClamAV, הצפנה. אודיו בלבד, מגבלת גודל.
- Audit: יצירת קישור, שימוש, ביטול, הצעת שאלה, אישור.
- הצעות מהמשפחה: המוטב חייב להיות מאושר באותה כספת (אחרת 404), עד 20 הצעות פתוחות למוטב, 300 תווים.
- ⚠️ מי שמחזיק בקישור יכול להקליט תשובה "בשם" המוריש. זה המחיר של "בלי סיסמה". מיטיגציות: תשובה אחת, 7 ימים, ביטול, והמוריש רואה כל תשובה שנכנסה דרך קישור (מסומנת "דרך קישור"). יש להנחות לשתף רק עם האדם עצמו.

## 4. נתונים
- `capture_links`: vault_id, token_hash, source (catalog/suggestion/custom), question_id, suggestion_id, question_enc, created_via (manual/weekly), expires_at, used_at, revoked_at.
- `question_suggestions`: vault_id, beneficiary_id, text_enc, status (pending/accepted/dismissed/answered).
- `capture_preferences`: vault_id, weekly_enabled, weekday (0–6), last_sent_on.

## 5. API
| Method | Path | גישה |
|---|---|---|
| GET/POST | `/vault/capture-links` (גוף: `source`, ואופציונלית `sendToMyEmail`), DELETE `/vault/capture-links/:id` | 🔒 מוריש |
| GET/PUT | `/vault/capture-preferences` | 🔒 מוריש |
| GET | `/vault/suggestions`, POST `/vault/suggestions/:id/accept`, `/dismiss` | 🔒 מוריש |
| GET/POST | `/inheritances/:vaultId/suggestions` | 🔒 מוטב מאושר, כספת בבנייה |
| POST | `/capture/session`, `/capture/answer` · PUT `/capture/audio` (כותרת `X-Capture-Token`) | ציבורי + טוקן + rate limit קשיח |

## 6. בדיקות
API: הנפקה ואימות טוקן, חד-פעמיות, תפוגה, ביטול, כספת נעולה, rate limit, שגיאה אחידה לטוקן שגוי, IDOR על קישורים והצעות, ניתוב התשובה למקום הנכון, הקלטה דרך הצינור, תזמון שבועי (יום, אידמפוטנטיות, עדיפות להצעות). E2E: מוריש יוצר קישור → העמוד נפתח בלי התחברות → תשובה → המוריש רואה; המשפחה מציעה → המוריש מאשר; axe.
