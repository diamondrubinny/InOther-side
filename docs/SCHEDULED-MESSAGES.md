# מסרים מתוזמנים לפי אירועי חיים ולוח עברי (שלב 6)

> מקור: מחקר מתחרים (#4, #14) — "ליבת הערך הרגשי בלי AI". לוח עברי הוא פער שאף מתחרה לא מכסה.

## 1. מה המשתמש חווה
- **המוריש (בחייו):** כותב מכתב/מסר ליקיר ובוחר **מתי** הוא יגיע אחרי מותו:
  | טריגר | דוגמה | חוזר? |
  |---|---|---|
  | עם פתיחת הכספת | "מכתב פרידה" | חד-פעמי |
  | תאריך לועזי | "1.9.2030 — היום הראשון באוניברסיטה" | חד-פעמי |
  | יום הולדת (לועזי / **עברי**) | "יום הולדת שמח, נכדה שלי" | לבחירה |
  | גיל (לועזי / **עברי**) | בר מצווה (13 עברי), בת מצווה (12), גיל 18 | חד-פעמי |
  | **יארצייט** (יום השנה העברי לפטירה) | "אל תהיו עצובים מדי היום" | לבחירה |
  | ימים אחרי הפטירה | סוף השבעה (7), **שלושים** (30) | חד-פעמי |
  | **חג** (נשלח **בערב החג**) | ראש השנה, יום כיפור, סוכות, חנוכה, ט"ו בשבט, פורים, פסח, שבועות | לבחירה |
  | תאריך שנתי (לועזי / עברי) | יום הנישואים | לבחירה |
  | **אירוע חיים** ("לפתוח כאשר...") | חתונה, לידת ילד, סיום לימודים, גיוס, "כשקשה לך" | נפתח ע"י המוטב |
- אפשר לצרף הקלטה/וידאו/תמונה מהכספת (קובץ נקי בלבד). קובץ מצורף **מוסתר** מכל מקום אחר (כולל הדמות) עד שהמסר נמסר.
- **תצוגה מקדימה**: "אם הייתי הולך היום, המסר יגיע ב-…" — מחושב בדפדפן באותו מנוע של השרת.
- **המוטב:** מקבל מייל עדין **בלי תוכן** ("מסר מ-X מחכה לך"); התוכן רק אחרי התחברות. רואה כמה מסרים עוד יגיעו בעתיד (בלי תאריכים), רשימת "לפתוח כאשר…" עם אישור לפני פתיחה, **השהיה** של כל המסרים ("אני עוד לא מוכן/ה") ו**עצירה** של מסר חוזר.

## 2. מנוע הלוח העברי (`packages/shared/src/calendar`)
- מימוש אלגוריתמי ללא תלות (Calendrical Calculations, Reingold & Dershowitz): מולד, דחיות, שנים מעוברות, חשוון/כסלו חסרים/מלאים.
- **אומת מול ICU** (`Intl` עם `calendar: "hebrew"`) לכל יום בין 1900 ל-2100 בבדיקה אוטומטית.
- **"אחרי השקיעה"**: לידה/פטירה אחרי השקיעה ⇒ התאריך העברי הוא של היום הבא (המשתמש מסמן).
- כללי יום הולדת/יארצייט לפי המקובל (כמו Hebcal): אדר ב׳/אדר בשנה לא מעוברת, ל׳ חשוון/כסלו שלא קיים, ל׳ אדר א׳.
  ⚠️ יש מנהגים שונים ביארצייט של מי שנפטר באדר בשנה פשוטה (אדר א׳ / אדר ב׳). ברירת המחדל: אדר א׳ (כמו Hebcal). **דורש אישור רבני/מקצועי לפני השקה.**
- "שלושים" נספר כאן מיום הפטירה (הלכתית — מיום הקבורה). מוצג כהערה למשתמש.
- המסירה ביום האזרחי בשעון `SCHEDULE_TIMEZONE` (ברירת מחדל `Asia/Jerusalem`); חגים — ביום שבערבו החג מתחיל.

## 3. נתונים
- `vault_beneficiaries`: + `birth_date_enc` (מוצפן), `born_after_sunset`, `messages_paused_at`.
- `release_requests`: + `death_after_sunset`.
- `scheduled_messages`: id, vault_id, title_enc, body_enc, trigger_enc (JSON מוצפן), trigger_kind (גלוי — נדרש לרשימת "לפתוח כאשר"), media_id.
- `scheduled_message_recipients`: message_id, beneficiary_id, status (pending/done/stopped), initialized, next_due_on (date; גלוי, מחושב רק אחרי הפתיחה).
- `message_deliveries`: message_id, beneficiary_id, occurrence_on, held (נמסר בזמן השהיה), delivered_at, opened_at. ייחודי לכל מופע ⇒ אידמפוטנטי.

## 4. תזמון (worker)
משימה `deliver_messages` כל שעה, ומיד אחרי `finalize_releases`:
1. **אתחול**: לכל נמען של כספת שנפתחה ולא אותחל — חישוב המופע הראשון; טריגר חד-פעמי שמועדו עבר (למשל "שלושים" בזמן תקופת ההמתנה) נמסר ביום הפתיחה ("catch-up").
2. **מסירה**: `next_due_on <= היום` ⇒ שורת delivery (ON CONFLICT DO NOTHING), חישוב המופע הבא (או `done`), מייל אם לא מושהה.

## 5. אבטחה ופרטיות
- תוכן, טריגר ותאריכי לידה מוצפנים במפתח הכספת (AAD לכל שורה). גלוי רק: סוג הטריגר ותאריך המסירה הבא.
- כל endpoint בודק בעלות/הרשאה בצד השרת; מוטב אחר / משתמש זר ⇒ 404 (IDOR נבדק בטסטים).
- מייל ללא תוכן. אין קישור "פתח בלי התחברות".
- **הגנה על קטינים (#14):** מוטב שגילו (לפי תאריך לידה) מתחת ל-18 — **שיחה עם הדמות חסומה** (`persona_minor_blocked`). מסרים כתובים מותרים. ⚖️ דורש בדיקה משפטית ומקצועית (פסיכולוגית) — כולל האם לשלוח עותק להורה/אפוטרופוס.
- תאריך לידה של מוטב הוא מידע אישי של צד שלישי: אופציונלי, נאסף רק לצורך תזמון, נמחק עם הכספת. יתווסף לטבלת המידע האישי.

## 6. API
| Method | Path | הרשאה |
|---|---|---|
| GET/POST | `/vault/messages` | מוריש מאומת |
| GET/PUT/DELETE | `/vault/messages/:id` | מוריש (כספת בבנייה) |
| GET | `/inheritances/:vaultId/messages` | מוטב שאישר, כספת פתוחה |
| GET | `/inheritances/:vaultId/messages/:deliveryId` | כנ"ל, רק delivery שלו |
| POST | `/inheritances/:vaultId/messages/:messageId/open` | כנ"ל, רק life_event |
| POST | `/inheritances/:vaultId/messages/:messageId/stop` | כנ"ל |
| PUT | `/inheritances/:vaultId/messages/pause` | כנ"ל |

## 7. בדיקות
- shared: התאמה ל-ICU ב-73,000 ימים; כללי יארצייט/יום הולדת; מנוע next-occurrence לכל טריגר.
- API: יצירה וולידציה, פתיחה ומסירה עם שעון מוזרק, catch-up, השהיה/חידוש, עצירה, life_event, IDOR, הסתרת קובץ מצורף, חסימת קטין.
- E2E: מוריש יוצר מסר ורואה תצוגה מקדימה עברית; axe.
